## 📚 What is JobGate?

**JobGate** is an AI-powered video interview platform that revolutionizes recruitment by:

- 🎥 Enabling asynchronous video interviews
- 🤖 Using AI to automatically evaluate candidates
- 📊 Providing detailed scores and feedback
- 💰 Being cost-effective (uses free AI services)
- 🔒 Ensuring secure and scalable operations

## 🎯 Key Highlights from the Analysis

### Technology
- **Backend:** Django 5.2.5 + Django REST Framework
- **Frontend:** React 19.1.1 + Bootstrap
- **Database:** PostgreSQL 16
- **AI:** Google Gemini + OpenAI Whisper
- **Infrastructure:** Docker + Docker Compose

### Features
- AI-powered question generation
- Automatic video transcription
- Intelligent candidate scoring
- Sentiment analysis
- Video storage (Cloudinary/Firebase)
- Email notifications (SendGrid)
- Secure authentication (JWT)
