## What is JobGate?

**JobGate** is an AI-powered video interview platform that:

- Enables **asynchronous video interviews** for recruitment
- Uses **Google Gemini AI** to automatically evaluate candidate responses
- Transcribes videos with **OpenAI Whisper**
- Provides **automated scoring and feedback** to recruiters
- Supports both **Recruiters** (creating interviews) and **Candidates** (submitting responses)

## Key Technologies

### Backend
- Django 5.2.5 + Django REST Framework
- PostgreSQL 16 database
- JWT authentication
- Cloudinary/Firebase for video storage
- SendGrid for emails

### Frontend
- React 19.1.1
- Bootstrap 5.3.7
- React Router
- Axios for API calls

### AI/ML
- Google Gemini (gemini-1.5-flash) - Content analysis
- OpenAI Whisper - Speech-to-text transcription
- VADER - Sentiment analysis
- PyTorch - Deep learning framework

### Infrastructure
- Docker + Docker Compose
- Nginx (production)
- Let's Encrypt SSL
